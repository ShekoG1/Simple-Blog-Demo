# SunEasy Blog

A light, modern, full-stack blogging web application built with C# and ASP.NET Core MVC, backed by a MySQL database using Entity Framework Core.

---

## 🛠️ Tech Stack

* **Framework:** ASP.NET Core 8.0 MVC
* **Language:** C#
* **Database:** MySQL
* **ORM:** Entity Framework Core (Pomelo MySQL Provider)
* **Frontend:** Razor Views, HTML5, CSS3, Bootstrap 5

---

## 📋 Features

* **View Blog Posts:** Home page listing all published blog posts in reverse chronological order.
* **Create Blog Posts:** Interactive form to draft and publish new posts directly to the MySQL database.
* **Responsive UI:** Clean, Bootstrap-powered navigation layout.

---

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed on your system:

* [.NET 8.0 SDK](https://dotnet.microsoft.com/download) or later
* [Visual Studio 2022](https://visualstudio.microsoft.com/) (with ASP.NET and web development workload)
* [MySQL Server](https://dev.mysql.com/downloads/mysql/) running locally
